# RoseLine 

A Django web app for tracking the family trees and bloodlines of horses in an RDR2 modded server after I got tired of trying to keep track of them manually with notes.

## Features

User accounts with profile avatars
Add and browse horses, with search/filter by breed, gender, status, and name
Full lineage tracking-  able to see a horse's sire, dam, grandparents, siblings, and offspring
Unit tests covering the relationship logic and access control

## Why I built this
Trying to track the family tree of the horses in this game kept getting harder and harder as the number of horses grew. I wanted something that was able to easily lay out the family tree and bloodlines, and siblings of the horses easily and in a simple way.

Stack: Django, Python, PostgreSQL (supabase), JavaScript, HTML/CSS
